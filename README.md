# ⏳ 시간의 틈 (Gap of Time)

> **"캘린더-시간표 일체형 스케줄러 & 성적 가중치 기반 수행평가 매니저"**

---

## 📌 주요 기능 구조

### 1. 📅 캘린더-시간표 일체형 매니저 (Calendar-Timetable Hybrid)
- **주차별 날짜 자동 연동:** 캘린더 피커 또는 `이전 주 / 다음 주` 버튼으로 날짜 이동 시 해당 주차의 요일별 날짜가 헤더에 자동 동기화됩니다.
- **D-Day 및 과목 자동 태깅:** 등록된 수행평가의 마감일과 과목 정보가 시간표 해당 교시 셀에 `🔥 [반영비율%] 제목` 형태의 배지로 실시간 표시됩니다.

### 2. ⚖️ 성적 반영 비율 가중치 계산기
- **우선순위 점수 공식:** 
  $$\text{Priority Score} = \frac{\text{성적 반영 비율 (\%)}}{\text{남은 일수 (Days Left)} + 1}$$
- 남은 기한과 성적 가중치를 고려하여 가장 효율적인 공부 순서를 자동으로 최상단에 배치합니다.

### 3. ⏱️ 뽀모도로(Pomodoro) 25분 몰입 타이머
- 등록된 수행평가를 지정하고 25분 몰입 세션을 진행할 수 있는 타이머를 제공합니다.

### 4. 🤖 Google Gemini AI 학습 코치 Integration
- Google Gemini API (`gemini-2.5-flash`)를 활용하여 과목별 수행평가 탐구 주제 제안 및 보고서 개요 작성을 조력합니다.

### 📤 친구 간 스케줄 코드 공유 (JSON Export / Import)
- 시간표 및 수행평가 일정을 단일 암호화 코드로 복사 및 불러오기하여 반 친구들과 공유할 수 있습니다.
