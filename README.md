# ⏳ 시간의 틈 (Gap of Time)

> **"학교 시간표 파악부터 수행평가 연동 알림, AI 대비 보조까지 — 시간이 부족한 학생들을 위한 스마트 매니저"**

---

## 📌 서비스 개요
- **서비스 이름:** 시간의 틈
- **의미:** 시간표와 수행평가를 한눈에 보여주고 유기적으로 연동하여, 바쁜 학생들에게 소중한 '시간의 틈'을 벌어준다는 의미
- **주요 사용자:** 수행평가와 학업 일정으로 시간이 부족한 중·고등학생
- **웹사이트:** `https://<your-github-username>.github.io/<your-repository-name>/`

## 💡 3대 핵심 개선 및 특장점

### 1. 🔄 '시간표' ↔ '일정 기록하기' 완벽 유기적 연동
- **STEP 2(일정 기록)**에서 수행평가(과목, 날짜)를 추가하면, **STEP 1(시간표)**가 자동으로 해당 요일과 과목을 추적합니다.
- 해당 요일의 시간표 셀에 **`🔥 수행 D-Day`** 배지와 하이라이트가 즉시 반영되어 복잡한 시간표 속에서 수행평가 과목을 한눈에 파악할 수 있습니다.

### 2. 📢 입체적 수행평가 알림 & 실시간 공지판
- **실시간 공지판:** 상단 공지 영역에서 D-0(오늘 마감), D-1(내일 마감) 등 임박한 수행평가를 카운트다운 형태로 즉시 보여줍니다.
- **입체적 알람:** 설정한 시각에 **[웹 푸시 알림 + 사운드 비프음 + 화면 팝업 공지]**가 동시 작동하여 중요한 제출 기한을 놓치지 않게 해줍니다.

### 3. 🤖 AI 수행평가 보조 튜터 (반복 없는 맞춤형 코칭)
- 다중 키워드 분석 알고리즘을 통해 **주제 추천, 3단 보고서 개요, 발표/PPT 팁, 신뢰성 있는 자료 조사법, 과목별 특화 가이드**를 매번 새롭게 제공합니다.
- 단축 버튼을 제공하여 질문 작성이 서툰 학생들도 클릭 한 번으로 가이드를 받을 수 있습니다.
