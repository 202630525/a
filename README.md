# ⏳ 시간의 틈 (Gap of Time)

> **"학교 시간표 관리부터 수행평가 연동 알림, Google Gemini AI 실시간 코칭까지 — 시간을 절약해주는 스마트 학업 매니저"**

---

## 📌 서비스 개요
- **서비스 이름:** 시간의 틈
- **의미:** 시간표와 수행평가를 한눈에 보여주고 유기적으로 연동하여, 바쁜 학생들에게 소중한 '시간의 틈'을 벌어준다는 의미
- **주요 사용자:** 수행평가와 학업 일정으로 시간이 부족한 중·고등학생
- **웹사이트 주소:** `https://<your-github-username>.github.io/<your-repository-name>/`

---

## 💡 주요 개편 및 핵심 기술

### 1. 🤖 Google Gemini AI 모델 직접 연동 (`gemini-1.5-flash`)
- **반복 없는 대화:** 고정된 답변 시뮬레이션을 탈피하고 Google Gemini REST API와 직접 연동하여 매번 새롭고 구체적인 수행평가 코칭을 제공합니다.
- **안전한 개인 API Key 방식:** 사용자가 Google AI Studio에서 무료로 발급받은 Gemini API 키를 직접 입력 및 저장(LocalStorage)하여 자유롭게 질문할 수 있습니다.

### 2. 🎯 15가지 지정 과목 옵션 시간표 및 유기적 연동
- **선택 드롭다운:** 시간표(STEP 1)와 일정 등록(STEP 2) 모두 지정된 15개 과목(`국어A`, `국어B`, `국어C`, `수학`, `영어`, `과학A`, `과학B`, `사회`, `역사`, `창체`, `체육`, `미술`, `가정`, `기술`, `한문`) 중에서 선택하도록 개편되었습니다.
- **실시간 🔥 배지:** 일정 등록 시 해당 요일 및 과목 시간표 셀에 `🔥 수행 D-Day` 배지가 자동으로 생성되어 시간표와 완벽히 유기적으로 연동됩니다.

### 3. 🔊 Web Audio API 기반 비프음 사운드 알람 (Sound Alarm)
- 설정한 수행평가 마감 시각이 되면 브라우저에서 **"삐- 삐- 삐-" 3연속 비프음 경고음**이 크게 울려 마감을 확실하게 인지시켜 줍니다.
